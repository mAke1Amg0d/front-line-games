# Front Line Games

Official website for Front Line Games, an independent Roblox studio.

[Visit the live website](https://make1amg0d.github.io/front-line-games/)

## Add another game

Open `games.js`, copy one existing object inside `window.FRONT_LINE_GAMES`, and
change its fields. The game grid, filters, total count, and hero artwork update
automatically.

Each game entry contains its title, Roblox link, thumbnail, category, short
description, and release status. No layout changes are needed when the catalog
grows.

## Update the website

Upload the changed files to the `main` branch of this repository. GitHub Pages
will publish the update automatically.

## Project

The site is a lightweight static build with no runtime framework or required
backend. It includes responsive layouts, game filters, accessibility support,
social sharing metadata, and a ready position for future games.
